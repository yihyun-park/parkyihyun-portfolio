GIS 수문정보시스템

관측소 데이터와 현장 인력의 위치·업무 현황을 실시간 모니터링하는 PC + 모바일 관제 플랫폼.

수문정보시스템의 GIS 데이터를 기반으로, 전국 수문 관측 지점과 현장 직원의 위치·업무 현황을 실시간으로 모니터링·관리하는 관제 플랫폼. 현장 대응 속도 향상 · 안전 점검 효율화 · 인력 배치 최적화를 목적으로 PC + 모바일에서 모두 사용 가능하도록 설계했습니다.

의뢰처
공공기관 운영기관
작업기간
2025.01 — 2025.03
역할
UI/UX (디자인 100%)
작업분야
PC OS + Mobile
01

4가지 문제를
4가지 결정으로.

기존 시스템은 PC와 모바일 화면을 동일하게 설계되어 있고 콘텐츠 구조가 복잡한 상태였습니다. 4가지 문제를 분석하고, 각각에 대응하는 디자인 의사결정으로 정리했습니다.

AS-IS

PC·모바일 동일 화면

PC 화면을 그대로 모바일에 적용 — 가독성·사용성 저하

TO-BE

Unified Tokens

PC·모바일이 같은 컬러·타이포·아이콘을 공유하는 통합 디자인 시스템. 디바이스 전환 시 학습 비용 0에 수렴.

AS-IS

지도 영역 협소

모바일에서 지도가 가려져 현장 직원이 위치 파악 어려움

TO-BE

Map-First

모바일에서 지도가 항상 화면 전체를 차지. 보조 기능(필터·검색·보고)은 플로팅 컨트롤로 분리해 한 손 조작 가능.

AS-IS

콘텐츠 구조 복잡

관측 데이터·인력·알림이 한 화면에 섞여 직관성 낮음

TO-BE

Information Hierarchy

좌측 목록 · 중앙 지도 · 우측 측정 현황으로 정보 위계를 분리. 그리드 시스템으로 정보 밀도와 시각 피로도의 균형을 잡았습니다.

AS-IS

보수적 팔레트

전통 관제 시스템 톤 — 현대적·기술적 인상 부족

TO-BE

#605BFF Main

전통 관제의 보수적 팔레트에서 벗어나 보라 메인 컬러. 상태 컬러(녹·황·적)와 시각 충돌을 피하면서 기술적 인상 부여.

02

같은 데이터를
두 화면으로.

같은 데이터를 PC 관제 화면과 Mobile 현장 화면 두 맥락으로 풀어냈습니다. PC는 통합 모니터링, Mobile은 현장 인력의 4단계 흐름.
